# Firefox extensions installed by `ucli apps` — the opinionated ones only.
#
# Format: one AMO addon ID per line (addons.mozilla.org ID, e.g. uBlock0@raymondhill.net).
# Lines starting with '#' are ignored.
#
# Which add-ons someone runs is personal, so this file ships empty on purpose:
# the repo does not decide your browser. Put yours in
#
#     ~/.config/ucli/firefox/personal-extensions.txt
#
# (copy personal-extensions.txt.example), which `ucli apps` installs too.
# `~/.config/ucli/firefox/dev-extensions.txt` is the same idea for `ucli devmode`.
#
# To find an extension's ID, open its addons.mozilla.org page and look for the
# ID in the URL or view-source.
